Esse é um projeto bem simples para auxiliar nos estudos de geometria analítica. Ele calcula a distância entre dois pontos,
as coordenadas do ponto médio entre eles e a área do triângulo de três pontos dados.

Eu criei um sistema para registrar ponto, com a intenção de reaproveitar os mesmos pontos para vários cálculos, porém olhando agora acho que é
uma função que talvez até dificulte um pouco mais pois o usuário tem que ficar lembrando dos nomes dos pontos registrados. Se eu
fosse fazer de novo faria de forma que o usuário digita-se as coordenadas na hora do cálculo.

Agora caso queira manter o sistema, uma oportunidade de melhoria seria transformar em uma lista encadeada.

Na questão de cálculos, principalmente na parte do determinante ficou bem manual mesmo, talvez tenha alguma forma mais eficiente de ser feita,
mas a lógica que eu usei foi literalmente como é feito na mão. Novamente, outra parte que ficou pouco eficiente foi a de leitura dos pontos e
a busca deles no vetor, adicionou uma complexidade a mais no código e não é uma função tão útil, mas foi um bom exercício.

Outras oportunidades de melhoria são implementar conceitos e cálculos mais avançados da geometria analítica.
